# SWYNEX Technologies Internship - Task 3: Interactive Dashboard

## 📌 Project Overview
This repository contains the interactive Power BI dashboard developed for Task 3 of the SWYNEX Technologies Internship. The goal was to transform cleaned E-commerce sales data into a high-impact, visual analytics dashboard to support business decision-making.

---

## 📊 Key Dashboard Features & Metrics

### 1. Executive KPI Cards
* **Total Revenue:** $5.11M
* **Total Orders:** 5K orders processed
* **Average Customer Rating:** 2.97 / 5.0
* **Average Delivery Days:** Operational efficiency tracking

### 2. Core Visualizations
* **Revenue by Product Category (Column Chart):** Highlights top-performing categories (Electronics and Clothing leading sales).
* **Revenue Distribution by Region (Donut Chart):** Visualizes sales contribution across West, North, South, and East regions.
* **Interactive Slicers:** Allows dynamic filtering by date ranges and geographic regions for real-time cross-filtering across all visuals.

---

## 🛠️ Tools & Technologies
* **BI Platform:** Microsoft Power BI Desktop
* **Data Source:** Cleaned E-commerce Sales Dataset (`cleaned_ecommerce_sales.xlsx`)
* **Visuals Used:** KPI Cards, Clustered Column Charts, Donut Charts, Interactive Slicers

---

## 💡 Business Insights
1. **Category Dominance:** Electronics ($1.83M) and Clothing ($1.53M) generate the majority of overall revenue.
2. **Regional Balance:** Revenue is evenly distributed across all 4 regions, with West leading slightly ($1.35M).
3. **Interactivity:** Cross-filtering reveals regional product preferences and performance trends.
